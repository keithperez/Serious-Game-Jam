## What is this game

We had one week to create and publish a game from scratch, fitting with the theme of "Spin to Win," and we settled on a turn-based rouge-like with procedural upgrades using the decorator design pattern to calculate damage to enemies based off of player upgrades, decisions, and the number the wheel landed on. It also has a chance to give out better upgrades based off of luck and is modular so putting in new upgrades is fast and easy. There are also super-rare upgrades that vastly increase the player's power.
